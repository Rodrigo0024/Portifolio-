SmartGate: Sistema Embarcado IoT

Controle de Acesso Inteligente com STM32 e Firmware em C (Baremetal/HAL)

Sobre o Projeto

O SmartGate é um projeto de hardware e software embarcado desenvolvido para gerenciar o controle de acesso automatizado de portões e catracas industriais ou residenciais. O sistema integra leitura de cartões RFID, autenticação biométrica local e conectividade sem fio para monitoramento remoto em tempo real.

Todo o projeto de circuito impresso (PCB) foi desenhado focando em alta imunidade a ruídos elétricos comuns em ambientes industriais, utilizando microcontroladores baseados na arquitetura ARM Cortex-M.

Principais Características

  • Firmware desenvolvido nativamente em Linguagem C utilizando bibliotecas HAL e rotinas otimizadas em Baremetal.
  • Placa de circuito impresso (PCB) desenvolvida no KiCad com isolamento galvânico nas entradas de relé.
  • Gerenciamento de filas e interrupções de hardware para leitura de teclado matricial e display OLED I2C.
  • Watchdog Timer (WDT) configurado para resgate automático de falhas em caso de travamento do sistema.
