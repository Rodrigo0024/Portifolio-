Estudos de Estruturas de Dados e Algoritmos em Python com Interface Interativa

Sobre o Projeto

Repositório dedicado aos estudos de estruturas de dados e algoritmos em Python, focado no aprimoramento da lógica de programação e na implementação prática dos conceitos fundamentais de ordenação.

O projeto conta com uma interface web interativa desenvolvida em Streamlit para testar e visualizar o comportamento dos algoritmos de forma dinâmica.

Progressos e Algoritmos

Acompanhamento dos algoritmos implementados e funcionalidades integradas no projeto:

  • Merge Sort: Implementado com recursão e função merge própria.
  • Quick Sort: Implementação eficiente baseada em partição.
  • Bubble Sort: Abordagem clássica baseada em trocas sucessivas.
  • Insertion Sort: Inserção ordenada eficiente para conjuntos menores.
  • Selection Sort: Seleção iterativa do menor elemento.
  • Interface Web com Streamlit: Painel interativo para testar e validar os algoritmos.

Como Executar

Certifique-se de ter o Python instalado na sua máquina. Siga os passos abaixo para configurar o ambiente e rodar o projeto:

1. Criar e ativar o ambiente virtual (venv)

Abra o terminal na pasta do projeto e execute:

No Linux / macOS:

python3 -m venv venv
source venv/bin/activate

No Windows (PowerShell):

python -m venv venv
.\venv\Scripts\Activate

2. Instalar os requisitos

pip install -r requirements.txt

3. Rodando o app

streamlit run app.py
